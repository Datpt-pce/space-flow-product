# Curated working library

This is the contributor subset adapted from the development repository's working rules.
Only the following skills are included; deployment, unrelated frameworks, personal memory,
automatic orchestration, local hooks and account configuration are excluded.

| Task | Read |
| --- | --- |
| Implement a requested change | [space-flow-change](skills/space-flow-change/SKILL.md) |
| Diagnose a bug | [space-flow-debug](skills/space-flow-debug/SKILL.md) |
| Review code and verify behavior | [space-flow-review](skills/space-flow-review/SKILL.md) |
| Trace callers and affected tests | [space-flow-impact](skills/space-flow-impact/SKILL.md) |
| Record task and evidence | [space-flow-harness](skills/space-flow-harness/SKILL.md) |

These are instructions, not additional agents that run automatically. Model/account selection
stays with the contributor. No subscription, token, API key, hook or personal MCP config is copied.
