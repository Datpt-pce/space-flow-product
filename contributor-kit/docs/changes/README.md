# Share a change note

Create one short Markdown file per contribution. Include the user-facing goal, before/after
behavior, affected areas, related PRs, tests actually run and remaining limitations. Add a UI
screenshot link when useful. Do not put credentials, account details, raw user data or local
absolute paths into the note.

Notes can accompany a PR. The trusted reviewer reads them as evidence supplied by the author;
they do not replace independent checks or authorize a release.
